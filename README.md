[Download installer](downloads/GolfSimHub-0.9.0-beta.18.exe) · [Complete beta package](downloads/FluJado-Golf-Sim-Hub-0.9.0-beta.18.zip)

## Fixed in beta.18

- GSPro and other previously disabled built-in tiles are activated when selected in Guided setup. Choose your hardware profile and save; existing active workflows are preserved unless you explicitly select replacement.
- Missing required connector/program paths are reported on Golf setup, before screens and Movies & TV.
- Update checks support numeric beta repair revisions.

This release is offered to existing beta.17 installations through the existing update feed. It enables repair versions such as beta.18.1 for future updates.

Install and activate simulator software and connectors first; verify a real shot outside the Hub. Upgrades preserve settings, licences and saved configurations. Vendor binaries and licences are not included. This beta installer remains unsigned.
