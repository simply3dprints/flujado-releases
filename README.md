## Latest closed beta: 0.9.0-beta.12

[Complete beta.12 package](downloads/FluJado-Golf-Sim-Hub-0.9.0-beta.12.zip) | [Windows installer](downloads/GolfSimHub-0.9.0-beta.12.exe)

[English guide](docs/beta.12/FluJado-Beta-User-Guide-EN.pdf) | [Dutch guide](docs/beta.12/FluJado-Beta-Handleiding-NL.pdf) | [Connector guide](docs/beta.12/FluJado-Connector-Setup-Guide-EN.pdf)

[Getting started with the new setup and settings](docs/beta.12/GETTING-STARTED.txt) | [Release notes](docs/beta.12/RELEASE-NOTES.txt) | [SHA-256 hashes](docs/beta.12/PACKAGE-RECEIPT.json)

Beta.12 adds guided software and connector discovery, an optional Movies & TV folder with service logos, a standalone custom tile option, and redesigned settings. Upgrades preserve existing settings and license storage. The package includes updated English and Dutch beta.12 guides with current screenshots, plus the connector setup companion. Voice control is a future roadmap item and is not included.

The automatic-update feed now offers beta.12 through the Hub; the installer checksum is verified before opening.
