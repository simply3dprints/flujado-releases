Update safely

Install the MSI over your existing GolfSimHub location or use Updates in the Hub. Do not uninstall first. Settings, local license state and custom flows are retained. An update does not extend a trial or activate a license. The installer lets first-time users choose a location and shortcuts. Install and activate your simulator software and connectors first, then confirm a real shot outside the Hub.

New in beta.18.6

Settings > ChatGPT flow now supports all 132 existing profile choices. These are software-tested catalog choices, not 132 hardware certifications. Assisted profiles keep their manual connection confirmations. Imported requests select built-in steps; arbitrary scripts are not supported. No setup or diagnostic file is sent automatically.

Current test scope

Muni and Drills ProTee VX and Square Omni shots were previously confirmed; VX roundtrips with GSPro were confirmed. Muni putting passed with VX and Omni. Drills received putts in Open Range, but its dedicated putting activity was not available. Additional monitor profiles remain hardware-untested. The beta.18.6 release adds software validation and configuration tests, with no new hardware claim.

Removal and recovery

Normal updates and repairs preserve your data. Keep my data and licence remains the default uninstall option. Explicit full removal removes the known local license stores as well as Hub data, without releasing an online activation; deactivate first when moving your license. The current MSI retains the two-store cleanup fix introduced in beta.18.5.

1. Export and ask ChatGPT

Open Settings > ChatGPT flow. Choose Export setup overview, then Copy ChatGPT prompt. Attach the JSON yourself in ChatGPT and describe your simulator, launch monitor and connector. Choose only a profile listed in availableProfiles / supportedRequests. The export contains fixed app IDs, software presence and versions, not local paths, license data or raw logs.

2. Import and review

Save ChatGPT's request JSON and choose Import ChatGPT request. Read the simulator, hardware route, concrete steps, screen choice and manual confirmations. Missing software or plugins must be configured locally first. Import does not start an app or save settings.

3. Apply with backup

Apply proposal and save settings writes the proposal and current Settings edits with an automatic configuration backup. The Hub returns to its dashboard. If the configuration changed since preview, import again. Existing saved flows are not silently replaced by a normal update; applying explicitly replaces the selected simulator tile.

4. Test your setup

Start the flow, check the connector/device connection, hit a real ball and check shutdown. Only you can confirm hardware success. Software presence or a community report does not prove your setup is ready.

5. Restore if needed

Open Settings > ChatGPT flow > Review last flow backup. Read the replacement warning, then Restore reviewed configuration. This restores the configuration from before the most recent assistant change and creates a backup of the current saved configuration. It replaces later configuration edits too. It does not change your license or simulator settings.

6. Share or request help

After a successful startup, real shot and shutdown test, choose the configured profile in the community selector, check the confirmation and Export for Discord. Share that file and your findings manually on the FluJado Discord server. If it fails, return to the Hub and Export Diagnostic Report. Contact FluJado on Discord with the chosen route, expected/actual result and exact error. Share the setup overview/request and send diagnostics privately when requested. Never send license keys, passwords, raw logs, config.json or a private full backup.

What does the Hub do?

FluJado Golf Sim Hub brings your golf simulator apps and their startup steps together in one Windows dashboard. Each tile runs a saved workflow: for example, opening a connector, waiting for a connection, then starting the simulator.

Prepare first

Install and activate your simulator software and the required connectors before FluJado. Verify a real shot outside the Hub. The Hub finds supported installed software; it does not install simulators, pair devices or supply their licenses.

First installation with MSI

1. Download FluJado-Golf-Sim-Hub-0.9.0-beta.18.6.msi and open it in your Windows account.
2. Select Next on Welcome. Choose your installation location; another drive is allowed. Keep GolfSimHub as the final folder name, for example C:\Golf\GolfSimHub.
3. Choose Add or Skip for the desktop shortcut and Start menu shortcuts. The Start menu also contains repair and uninstall options.
4. Review the path and select Install.
5. Start FluJado is checked by default on the final page. Select Finish to open it, or uncheck the box to finish without starting.
6. Use Guided setup to choose your software, connector route and screens.

Automatic update notices

The open Hub checks about 15 seconds after startup, then every six hours. A newer-version notice appears when no workflow is active and Presentation mode is off. Click the notice to review the update, or use Updates > Check for updates. You choose when to install; there is no forced installation and no notice while the Hub is closed. SHA-256 is checked before the update is opened. Offline use remains available.

Existing beta.18 EXE installation

Use the update notice in the Hub. A one-time MSI transition starter contains the same official MSI, verifies it, waits for the Hub to close, creates and checks a private backup, then opens the MSI wizard on your existing folder. Keep that folder selected. This EXE is only a bridge for older clients; new users download MSI. If another FluJado MSI installation already exists, update it directly.

Earlier betas and MSI previews

Beta.17 and earlier may not understand revision numbers such as beta.18.6. Make a private backup, close the Hub and install the current MSI into your existing GolfSimHub folder. Do not uninstall first or delete data. Existing MSI preview users can install the current MSI directly. Keep settings, license state and your original installation path.

What an update preserves

Settings, saved configurations, workflows, custom artwork and existing local license state are retained. Updating does not restart or extend a trial and does not automatically replace saved workflows with newer presets. Back up before migration and keep backups private; they may contain license information and local paths.

Repair and interrupted updates

Use Start menu > FluJado > Repair FluJado. Repair restores the current application version; it is not a downgrade or a settings reset. MSI updates use a separate worker and a verified recovery MSI. If an update fails or is cancelled, keep the error and private backup, allow recovery to finish and check the installed version before retrying. Do not manually delete installer caches or recovery packages. If recovery reports incomplete, stop and contact support.

Uninstall and data choice

Close the Hub and use Start menu > FluJado > Uninstall FluJado (data options). Keep my data and licence is selected by default. The explicit Remove all Hub data and the local licence option also erases shared local Hub license storage for this Windows account. It does not release an online activation; use License > Deactivate this PC first if moving your license. Windows Installed apps/native MSI removal keeps personal data by default. Read the final completion message before closing. Simulator software is left untouched. If Start menu shortcuts were skipped, Windows Installed apps remains available for repair/removal with the default data retention.

If Windows blocks the download

The MSI and transition starter are currently unsigned. A reputation notice and an antivirus detection are different reports. Use the official link and keep the exact message. If antivirus blocks or quarantines a file, stop and contact support. Keep protection enabled; do not add exclusions or restore quarantined files to continue. Never send license keys, passwords or full private backups.

Before you begin

The welcome page repeats the required order: install and test the simulator and connectors first, then set up FluJado. If those programs are not ready, finish their installation before scanning.

Open the guided setup

Open Settings > Overview > Open guided setup, or use Setup wizard... at the top. Save editor changes first: the wizard reads the last saved configuration. On a new PC the initial setup takes you here. No simulator is launched during setup.

1. Welcome / 2. Software discovery

Click Find my software. Select supported simulators and review found program locations. The Hub also looks for supported connector apps needed by your selected routes. Scan this PC again repeats discovery. A found executable is not proof of a working device connection. Missing or unusual installations can be located manually.

3. Hardware routes and program locations

Choose the correct launch-monitor and connector preset for each selected simulator. Use Locate selected program... and Check locations for missing paths. Existing active workflows and paths are kept unless Replace selected existing golf workflows with the chosen presets is explicitly selected. Skip golf setup for now supports an entertainment-only setup. Add a standalone empty tile is optional; configure its program later in Settings. Selecting a built-in simulator also enables its previously disabled tile. Required missing program or connector paths are reported here, before Screens and Movies & TV. Existing active workflows are preserved unless you explicitly choose replacement.

4. Screens

Choose Simulator screen and Hub controls and launcher updates; the same display may do both. Use Identify screens and Refresh screens when needed. Keep all my existing screen settings preserves current routing. Monitor identity is saved; resolutions and driver settings remain under your control in Windows and the simulator.

5. Movies & TV / 6. Review and save

Optionally choose streaming shortcuts, then review the summary. Back returns to earlier steps. Save applies the choices and backs up the previous configuration; Cancel leaves the saved setup unchanged. Verify a real shot manually after adding a new hardware route.

Start a workflow

1. Turn on your launch monitor and make sure its required cable or network connection is available.
2. Click the desired tile once.
3. Follow the status at the bottom of the dashboard. The Hub runs the steps in order.
4. Wait for the workflow to finish, then test a real shot in the simulator.

Waiting for a connection or update

A wait often checks whether an app is ready, rather than simply pausing for a fixed time. The supported rēlā workflow checks its connection and opens rēlā minimized. Other workflows may need a manual step. Click Continue only after completing the instruction shown.
If ProTee or another app requests an update, perform it in that app. Supported workflows wait for readiness to return. If the workflow reports an error or keeps waiting, use the troubleshooting steps in Troubleshooting; do not simply bypass the check.

Switch to another simulator or route

Wait for the current workflow to finish, then click the other tile. Switching between the built-in ShotForge routes performs a clean start: the involved apps and connectors are closed and reopened. Finish your session first. Custom workflows perform only the steps saved in them.

Dashboard controls

Retry retries a failed step when available. Cancel stops the active workflow; apps already opened may remain running. Close all apps closes the apps listed in Settings > Startup & shutdown. Review that list before using the button. Full screen or F11 toggles the Hub's full-screen view; Esc goes back.

A practical startup test

Start the same tile three times, switch to another app or route if available, then restart the PC. Check window placement and actual shot delivery. Record your launch monitor, firmware, simulator version and connector version. Successful startup alone is not proof of a working golf connection.

A clearer settings overview

Start on Overview. Use the sidebar to choose a section. Save changes stores editor changes; Close without saving discards them. Windows startup and administrator-code actions apply immediately. Expand technical readiness rules and workflow steps only when needed.

Configure the optional Your app tile

Click Your app to open Settings. Add its executable in Apps & connectors. Select the draft under Tiles & screens, give it a name, add the intended steps under Advanced workflow steps, enable it and Save changes. The empty tile launches no demo software.

Add an app

Open Settings > Apps & connectors. Click Add app, give the app a recognizable name, then use Choose .exe... to select its executable. Use Arguments only if the app needs them. Additional process paths identifies an extra process opened by a launcher; change this only when you know which process belongs to the app.

Create a tile

Open Tiles & screens > Add tile. Enter Name and Subtitle, choose the destination under Open on display, and enable the tile. A tile contains steps that refer to your configured apps. The setup starter tile disappears once a real enabled tile exists. Use Move up and Move down to reorder tiles or selected steps.

Add workflow steps

Expand Advanced workflow steps first. Select a tile and click Add step. Choose Action and App.
ensureStarted: makes sure the app is running.
waitReady: waits for the app's configured readiness check.
launch: launches the selected app as part of the workflow.
close: closes the selected app.
restart: closes and starts the app again.
waitUser: asks for manual confirmation.
invokeButton and connectAwesomeGolf are specialized steps; use the supplied profiles for these whenever possible.

A simple example

For an app without a connector, add the app, create a tile and add an ensureStarted step for that app. Click Save and test the tile. For a simulator with a connector, start with the Setup wizard instead. A readiness step requires the correct readiness rules for that app. Do not copy status words from a different launch monitor.

Save and share

Click Save to keep your edits; Close without saving discards ordinary editor changes. Use Share workflows to export a tile or import a shared workflow. Imports are reviewed first and added as disabled tiles. Configure all local app paths and any additional process paths, review the steps, enable the tile and click Save changes. A community workflow is not a compatibility guarantee. Do not share a full backup when you only want to share a workflow.

Choose your services

In Guided setup, open Movies & TV and select only the services you use. The list includes 22 services with local logos. All services, US and Europe filter the list without clearing hidden selections. Leave every service unchecked to omit the folder. Availability and subscription requirements vary by country.

Open a service and return to golf

Click the cinema-style Movies & TV tile on Home. Its service tiles open inside the same dashboard. Choose a service to open its official website in your default browser; use your own account and subscription. Back to golf or Escape returns to the previous golf-tile page. No streaming passwords are stored by FluJado.

Change your selection later

Save any settings edits, reopen Guided setup and change the Movies & TV choices. Leave replacement of existing golf workflows off to retain those routes. Review and save. Voice commands are not included in beta.18.6.

An automatic 14-day Pro trial

The full Pro trial begins when you first open the Hub. No key or payment details are needed. Updating or reopening does not renew the trial. After 14 days, all Hub functions are locked except the license screen and exiting. Your settings, workflows and images are retained. A valid Home or Pro activation restores access to your existing setup.

Activate a test license

1. Connect to the internet and check your Windows date and time.
2. Click License at the top, or Activate Home or Pro after the trial ends.
3. Check Licensing channel: this beta uses the test channel. Use the Home or Pro test key supplied by FluJado.
4. Paste it into License key and click Activate.
5. Wait for License activated successfully. Check that the correct edition is shown, then close the window.
6. Test your existing tile again. Activation does not require replacing your setup.

Home and Pro

Home includes the dashboard, app launching and management, custom workflows, workflow import/export and saved configurations. There is no limit based on the number of launch monitors you add. Pro adds custom branding, text, logos and backgrounds, Presentation mode and local Backup & Restore. The trial provides Pro. One license is intended for one active simulator PC.

Offline use and moving to another PC

Initial activation, Check online and Deactivate this PC require internet access. A locally activated license can then be used offline; include this in your beta test. To move: on the old PC, open License > Deactivate this PC and wait for confirmation, then activate on the new PC. Do not copy a local license file.

Clock warnings or activation errors

Do not turn the PC clock back to extend the trial. The Hub checks for clock rollback and remembers trial expiry. If a clock warning appears, restore the correct Windows date, time and time zone. Contact support if it persists. If activation was interrupted, try Activate again with the same key. Test keys are not proof of purchase. The website button opens FluJado.com; a live checkout is not yet guaranteed.

Saved configurations - Home and Pro

Save Settings first. Open Configurations on the dashboard, enter a recognizable name and click Save changes current configuration. Later, select a saved item and click Use selected configuration. This changes Hub settings; running apps stay open. The Hub automatically saves the previous configuration before switching. A configuration is a saved setup, not a license for a second PC.

Customize the appearance - Pro

Use Settings > Appearance (Pro) for your logo, tagline, welcome text and colors. Set the background under Startup & shutdown. Adjust individual tile images under Tiles & screens. A transparent PNG is recommended for logos. Click Save. Home uses the default appearance.

Presentation mode - Pro

In Settings > Presentation (Pro), use Set / reset administrator code... and enter the code twice. This change applies immediately, without Save. Open Presentation on the dashboard for the guest view. Use the code to return to normal controls. Forgotten the code? Close and reopen the Hub, go to normal Settings and set a new code. Presentation mode is not a secure Windows kiosk.

Create a local backup - Pro

Save Settings first. Open Backup & restore > Create backup... and store the file somewhere safe. The export includes your current saved configuration, workflows, paths, screen choices, appearance and configured images. It does not include simulator installations, their data or licenses, the Hub license or Windows startup registration. Named Configurations and their images are included too. Beta.6 backups require beta.6 or later; beta.5 backups remain readable.

Restore a backup - Pro

Choose Restore backup..., review the proposed changes and confirm only the restore you want. Restore replaces the current saved configuration and discards unsaved editor changes. Named configurations are added as new copies; existing saved configurations are retained. A recovery backup of the current configuration and named library is created automatically first. On another PC, app paths and screens may be unavailable. Fix these before re-enabling disabled tiles. A full backup contains local paths and settings; share it only deliberately.

No tile or an app will not start

If you see Set up your first app, no real tile is enabled yet. Use the wizard or add and enable a tile, then click Save changes. For a startup error, check executable paths under Apps, the selected route and whether the app opens on its own. If the trial has expired, activate a valid license first.

A workflow keeps waiting

Read the exact status. Check the relevant app for an update, error or missing connection. Use Retry after fixing the cause. If it still fails, cancel the workflow and save the message and log. Mention whether you quickly entered Range or another mode. The built-in ShotForge workflow recognizes several modes, but software updates may require new readiness checks.

Wrong screen or resolution

Use the wizard to select Simulator screen and Controls and updates screen again. Confirm them with Identify screens and save. Set game resolution in the simulator or Windows rather than choosing an unrelated screen profile. If the problem returns, report your display, cable routing and resolution.

Installation or removal fails

Check that the selected folder is the actual existing GolfSimHub installation. Let any workflow finish, close the Hub and retry. Use the MSI repair route described in chapter 1. Do not use the old EXE Restore previous Golf Sim Hub shortcut on an MSI installation or delete unknown folders to bypass an error. MSI update recovery requires its verified recovery package. Keep the exact message and private backup; contact support if recovery is incomplete.

Add a screenshot and the reviewed report if helpful. Hide license keys, passwords and personal information. Reports are not sent automatically.
