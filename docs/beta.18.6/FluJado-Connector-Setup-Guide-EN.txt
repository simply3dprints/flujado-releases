Install the MSI over your existing GolfSimHub location or use Updates in the Hub. Do not uninstall first. Settings, local license state and custom flows are retained. Settings > ChatGPT flow now supports all 132 existing profile choices. These are software-tested catalog choices, not 132 hardware certifications. Removal and recovery

Normal updates and repairs preserve your data. Keep my data and licence remains the default uninstall option. Explicit full removal removes the known local license stores as well as Hub data, without releasing an online activation; deactivate first when moving your license. The current MSI retains the two-store cleanup fix introduced in beta.18.5.

1. Export and ask ChatGPT

Open Settings > ChatGPT flow. Choose Export setup overview, then Copy ChatGPT prompt. Attach the JSON yourself in ChatGPT and describe your simulator, launch monitor and connector. Choose only a profile listed in availableProfiles / supportedRequests. The export contains fixed app IDs, software presence and versions, not local paths, license data or raw logs.

2. Import and review

Save ChatGPT's request JSON and choose Import ChatGPT request. Read the simulator, hardware route, concrete steps, screen choice and manual confirmations. Missing software or plugins must be configured locally first. Import does not start an app or save settings.

3. Apply with backup

Apply proposal and save settings writes the proposal and current Settings edits with an automatic configuration backup. The Hub returns to its dashboard. If the configuration changed since preview, import again. Existing saved flows are not silently replaced by a normal update; applying explicitly replaces the selected simulator tile.

4. Test your setup

Start the flow, check the connector/device connection, hit a real ball and check shutdown. Only you can confirm hardware success. Software presence or a community report does not prove your setup is ready.

5. Restore if needed

Open Settings > ChatGPT flow > Review last flow backup. Read the replacement warning, then Restore reviewed configuration. This restores the configuration from before the most recent assistant change and creates a backup of the current saved configuration. It replaces later configuration edits too. It does not change your license or simulator settings.

6. Share or request help

After a successful startup, real shot and shutdown test, choose the configured profile in the community selector, check the confirmation and Export for Discord. Share that file and your findings manually on the FluJado Discord server. If it fails, return to the Hub and Export Diagnostic Report. Contact FluJado on Discord with the chosen route, expected/actual result and exact error. Share the setup overview/request and send diagnostics privately when requested. Never send license keys, passwords, raw logs, config.json or a private full backup.

Windows English OCR and the recognised executable hash are required. Keep the launcher visible and still. Recognition is relative to the launcher window, so another screen/location is supported by design; moving/resizing during recognition rejects the click. Other builds or unavailable OCR require the assisted route.

What still needs testing

Automatic Connect and Start VTrack bridge control remains untested with VTrack hardware. Connected/Bridge running describes the interface, not proven device readiness. Confirm device discovery, Auto-send shots, Club/Hand and a real shot in Infinite Tees. Stop on errors. Uneekor additional information is pending; Muni and Drills have released profiles; consult the compatibility table for the tested and untested combinations. See the current compatibility table for each route; no new hardware testing was performed for these manuals.

Review scope

Hub/MSI documentation checked on 20 October 2026. Existing vendor reference prose originates from the 16-17 October review. Link availability is checked separately; a reachable download does not verify binary safety or exact hardware compatibility. No connector binaries or license data are included.

Drills setup and game choice

Install and sign in to Drills and configure your connector first. In FluJado open Settings > Overview > Open guided setup, enable Drills, and choose your exact launch monitor and route. Existing active flows stay unchanged unless you explicitly select replacement. To apply an updated preset to an existing route, back up first and explicitly replace that selected workflow.

Screens and startup

Keep your existing screen selection. New simulator profiles inherit the configured simulator screen, including older installations with one shared per-tile screen choice. The physical monitor identity is used, not its changing Windows display number. Drills opens on that screen and leaves game selection to you: Open Range is never chosen by FluJado.

ProTee VX and Square Omni

These two Drills routes connected and delivered real shots in local tests. ProTee VX switching with GSPro also passed. A GSPro/Omni shot was not verified in that switching session because the installed GSPro connector offered only ProTee. A controlled one-time ProTee startup recovery is available; its recovery branch was tested with isolated fixtures.

Other launch monitors

15 additional Drills profiles show Not tested (assisted). They require one manual connection confirmation and are not automatic proof of device readiness. Square HE, Garmin R10, SkyTrak OG/+/Max, Bushnell LPi and native VTrack have device-specific Discord guidance. The remaining rela combinations are candidates based on documented connector inputs and the Drills output. Check the compatibility table for each exact profile.

VTrack and LPi

The native VTrack route uses VTrack in the Drills launcher, not Other, with VTrack Toolkit and the Infinite Tees bridge closed. LPi uses the compatible OtherForesightPlugin.dll beside rela.exe; conflicting ProTee/Other plugins are rejected. Plugins are not bundled.

Off-center hitting mat

During a drill, press Esc and inspect its camera settings. Adjust the view for your own mat and verify the result visually. No universal numeric offset is documented here. FluJado updates preserve Drills settings and do not set the camera offset.

ShotForge and MSI update

ShotForge startup/readiness and supported connector checks have been improved. The MSI upgrade order now handles newly added application files before finishing the upgrade; rollback and cancellation were tested in an isolated product family. The update does not replace saved workflows automatically.
