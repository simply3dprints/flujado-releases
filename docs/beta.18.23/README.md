## Nederlands

Deze bèta bevat verbeteringen voor het afsluiten van GSPro, PurePlay en GolfCore, updatevoortgang in vier stappen en automatische ProTee VX-koppeling voor Awesome Golf. De Hub controleert benodigde losse plug-ins voor rēlā-routes. De GC3-routes voor PurePlay en Muni wachten op een hardwaretest. Remote Control volgt apart.

## English

This beta includes fixes for closing GSPro, PurePlay and GolfCore, a four-stage update progress display and automatic ProTee VX connection in Awesome Golf. The Hub checks required plug-ins on rēlā routes. GC3 testing with PurePlay and Muni still needs hardware testers. Remote Control will follow separately.
