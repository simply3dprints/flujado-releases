# Connector setup guide

For beta testers | 20 October 2026

Windows / FluJado beta.18.3. Install and test simulator and connector software before handing startup to the Hub.

FluJado beta.18.3 setup and updates

MSI is the standard installer. Use the installation guide included in this document, then Settings > Overview > Open guided setup to find supported software and connectors. Choose the exact model and route. Missing required program paths are reported before screens and Movies & TV. Selecting a built-in simulator enables its disabled tile; existing active workflows remain unless replacement is explicitly selected. A discovered executable is not a verified device connection.

Start with these three choices

Write down your launch monitor model, simulator and connection route. A ProTee-to-ShotForge route through rela uses different software from its VX Connector route. A Square setup must not inherit ProTee settings.

What a connector does

A connector forwards launch-monitor data to the simulator. FluJado starts configured applications and checks workflow readiness; it does not replace the connector, install vendor software or turn a listed profile into a verified hardware integration.

Read only the route you need

Section 1: downloads. Section 2: ShotForge with rela. Section 3: ProTee alternatives. Section 4: GSPro direct routes. Section 5: GSPro vendor/community routes. Section 6: Awesome Golf. Section 7: troubleshooting. The model index covers all 132 presets in beta.18.3.

Status and scope

This is a setup companion, not a universal compatibility guarantee. Presets are a mixture of locally exercised, vendor-documented and community-assisted routes. Most need independent hardware testing. Keep the software maker's current model guide alongside this document.

Before installing anything

Finish your current simulator session. Note existing connector settings and versions. Download from the maker or the linked author page. Keep required vendor/simulator licenses active. If a file source or exact model is unclear, ask before replacing anything. Connector binaries are not included in the FluJado package.

# FluJado installation and maintenance - beta.18.3

Current download

https://raw.githubusercontent.com/simply3dprints/flujado-releases/main/downloads/FluJado-Golf-Sim-Hub-0.9.0-beta.18.3.msi
Release notes: https://github.com/simply3dprints/flujado-releases/blob/main/docs/beta.18.3/RELEASE-NOTES.txt
Compatibility and test status: https://github.com/simply3dprints/flujado-releases/blob/main/COMPATIBILITY.md

Prepare first

Install and activate your simulator software and the required connectors before FluJado. Verify a real shot outside the Hub. The Hub finds supported installed software; it does not install simulators, pair devices or supply their licenses.

First installation with MSI

1. Download FluJado-Golf-Sim-Hub-0.9.0-beta.18.3.msi and open it in your Windows account.
2. Select Next on Welcome. Choose your installation location; another drive is allowed. Keep GolfSimHub as the final folder name, for example C:\Golf\GolfSimHub.
3. Choose Add or Skip for the desktop shortcut and Start menu shortcuts. The Start menu also contains repair and uninstall options.
4. Review the path and select Install.
5. Start FluJado is checked by default on the final page. Select Finish to open it, or uncheck the box to finish without starting.
6. Use Guided setup to choose your software, connector route and screens.

Automatic update notices

The open Hub checks about 15 seconds after startup, then every six hours. A newer-version notice appears when no workflow is active and Presentation mode is off. Click the notice to review the update, or use Updates > Check for updates. You choose when to install; there is no forced installation and no notice while the Hub is closed. SHA-256 is checked before the update is opened. Offline use remains available.

Existing beta.18 EXE installation

Use the update notice in the Hub. A one-time MSI transition starter contains the same official MSI, verifies it, waits for the Hub to close, creates and checks a private backup, then opens the MSI wizard on your existing folder. Keep that folder selected. This EXE is only a bridge for older clients; new users download MSI. If another FluJado MSI installation already exists, update it directly.

Earlier betas and MSI previews

Beta.17 and earlier may not understand revision numbers such as beta.18.3. Make a private backup, close the Hub and install the current MSI into your existing GolfSimHub folder. Do not uninstall first or delete data. Existing MSI preview users can install the current MSI directly. Keep settings, license state and your original installation path.

What an update preserves

Settings, saved configurations, workflows, custom artwork and existing local license state are retained. Updating does not restart or extend a trial and does not automatically replace saved workflows with newer presets. Back up before migration and keep backups private; they may contain license information and local paths.

Repair and interrupted updates

Use Start menu > FluJado > Repair FluJado. Repair restores the current application version; it is not a downgrade or a settings reset. MSI updates use a separate worker and a verified recovery MSI. If an update fails or is cancelled, keep the error and private backup, allow recovery to finish and check the installed version before retrying. Do not manually delete installer caches or recovery packages. If recovery reports incomplete, stop and contact support.

Uninstall and data choice

Close the Hub and use Start menu > FluJado > Uninstall FluJado (data options). Keep my data and licence is selected by default. The explicit Remove all Hub data and the local licence option also erases shared local Hub license storage for this Windows account. It does not release an online activation; use License > Deactivate this PC first if moving your license. Windows Installed apps/native MSI removal keeps personal data by default. Read the final completion message before closing. Simulator software is left untouched. If Start menu shortcuts were skipped, Windows Installed apps remains available for repair/removal with the default data retention.

If Windows blocks the download

The MSI and transition starter are currently unsigned. A reputation notice and an antivirus detection are different reports. Use the official link and keep the exact message. If antivirus blocks or quarantines a file, stop and contact support. Keep protection enabled; do not add exclusions or restore quarantined files to continue. Never send license keys, passwords or full private backups.

# Muni Golf Sim - beta.18.3

Muni: install and choose your route

Install Muni and sign in normally. Install and configure rela and any required launch monitor plugin first. Confirm a shot outside FluJado. In Settings > Overview > Open guided setup, enable Muni Golf Sim and select your exact launch monitor. New profiles inherit your simulator screen. Existing custom workflows remain unchanged unless you explicitly replace the selected route.

ProTee VX and Square Omni

Muni real shots and automatic startup passed locally for both. Muni > GSPro > Muni with ProTee VX passed with real shots in both games. Square Omni switching with GSPro is outside this test scope. One earlier VX startup stalled before Labs appeared; later restarts and the GSPro return passed. Putting and reboot tests remain pending.

Automatic startup

FluJado starts Muni, verifies its local receiver on port 9210, closes the bundled native connector and launches rela. For VX the plugin starts ProTee Labs. Choose your activity in Muni; the Hub does not automatically load a range. Keep a ball in the hitting area for the Omni readiness check.

Other Muni monitors: not tested

Fourteen additional assisted profiles cover Square HE, Garmin R10, SkyTrak OG/+/Max, NOVA, Mevo+/Gen2/Xi/X2, GC2, GolfJoy, Full Swing KIT and Bushnell LPi. They are inferred rela adapter combinations, not hardware compatibility confirmations. Select the exact device and Muni Golf Sim in rela, set its Muni game port to 9210, connect the device first and confirm both connections. Normal vendor setup and any specified plugin are required.

Updated tile artwork

Drills, Infinite Tees and Muni use their official logos and updated artwork. The PLAY label and broken arrow text have been removed from simulator tiles. Your own tile artwork and settings are retained.

# 2. ShotForge with rela

Install once

Install your required manufacturer software and ShotForge first. Run normal vendor activation and updates. Install rela, select only your owned devices and the simulator output you use, and review the setup results. Resolve red setup results before continuing. Source: rela installation guide.

Manufacturer prerequisites

SkyTrak, GolfJoy and FlightScope Xi/X2 need the appropriate installed vendor app for rela's local checks. Install rela on the same disk when its setup requires compatibility linking. GC2 USB may need its driver. Square, Mevo+/Gen2, R10 and KIT do not require installer-managed vendor component links according to rela's FAQ; normal pairing and entitlement requirements still apply. Source: Device requirements.

First connection

Turn on the monitor, open ShotForge, then open rela. Select the correct Device and connection type, use Search, and check the Simulator selection. Wait for both sides to connect and verify one real shot. Auto Connect and Discover can automate subsequent device search. Source: First connection and settings.

In FluJado

Choose the ShotForge preset for your model and the rela route. Browse to the actual ShotForge launcher, game executable and rela.exe. Use your own folders. The built-in flow opens ShotForge before rela. Do not add VX Connector, VGPConnect or ProTee Labs to a Square route.

Several launch monitors

A saved rela default is not an automatic device switch for every setup. Confirm Device, connection type, simulator and plugin for the monitor you are about to use. The Hub has no Home/Pro hardware-count restriction.

Pass this test before automating

Device connected; simulator connected; real shots arrive. Repeat after restarting the PC. A green installation result or a running process alone is insufficient. Record exact versions and the chosen route.

# 3. ProTee VX to ShotForge

Route A - rela with a ProTee plugin

This is a community plugin route. The community plugin collection was reposted by eKsiSLe in the ProTee channel on 8 October. Confirm the ProTee DLL and version with the author before installing: the collection contents were not downloaded or validated here.

Plugin placement

After closing rela, put only the selected Other-device plugin next to rela.exe, not inside the FluJado folder. The developer API discovers plugins from the application directory. Avoid multiple competing Other plugins. Source: rela Other plugin discovery.

ProTee-specific configuration

The route recorded for this beta uses Device = Other and the ProTee plugin's Socket Relay settings. Follow the plugin author's Find/Save/restart instructions for your version. This is not the Square connection setting. Start ShotForge before rela. The plugin may manage the Labs restart; finish updates before testing. Verify shots manually before enabling the Hub flow.

Route B - VGPConnect / VX Connector

The existing Hub preset starts ProTee Labs, waits for it, opens VGPConnect and VX Connector, opens ShotForge, then restarts VGPConnect after ShotForge becomes ready. Use the supplied executable paths from your working installation. Get VX Connector from the author repository. Its author documents tray selection Switch to Drills; the ShotForge community route uses that target. ProTee Labs 1.12.9.0 or later requires VX Connector 1.4.0 or later. The repository documents InfiniteTees/Drills; ShotForge use is community guidance, not manufacturer certification.

Choose one route

Select the matching connector-labelled preset in the Hub wizard. When switching between these ShotForge routes, end the session first: the Hub closes and restarts the configured apps/connectors. Entering Range quickly was checked locally, but other PCs still need testing.

If a required file is missing

Stop and obtain the correct file from the author. Do not remove the Hub preflight requirement to force a launch. Ask the tester to provide the pinned author post, version and successful manual connection result.

# 4. GSPro - direct/native routes

Common installation

Use GSPro's installer guide and the exact model connection page from GSPro setup documentation. Activate GSPro for the intended device and perform the initial connection in GSPro Connect. Configure GSPLauncher.exe in FluJado; selecting a Hub profile does not change your GSPro license type.

ProTee VX

Install and activate ProTee Labs and enable its GSPro connection through the vendor procedure. Keep the required GSPro/API connection available and configure Labs Game Options. Then select the ProTee VX GSPro preset in FluJado. Source: ProTee GSPro activation.

Garmin R10 and R50

Use the separate R10 or R50 guide. Do not assume the pairing/network steps are the same. The Hub's native presets launch GSPro; they do not run rela. Configure the monitor connection, firmware and simulator settings manually first. Open the matching guide from the model index.

Rapsodo MLM2PRO

Use the GSPro MLM2PRO guide for required authentication, entitlement and connection steps. The current Hub preset includes a manual preparation confirmation before launch. That preset is separate from the ShotForge Other-plugin route. Do not treat the presence of a plugin DLL as successful authentication.

FlightScope, Foresight/Bushnell and GolfJoy

Use the official model guide and current simulator entitlement. Native presets launch GSPro after conflict cleanup. Connection and license conversion must already be completed outside the Hub. Do not copy rēlā vendor-link instructions into a native GSPro setup.

Square

The local Omni GSPro setup used the native GSPro Connect route with a Square-enabled GSPro license. The separate Square GSPro Connector download is an alternative documented by Square; do not install it on top of a working direct route without choosing that route deliberately. Home Edition and Omni are distinct models.

# 6. Awesome Golf

Download and choose your exact model

Awesome Golf's official compatibility list links individual connection guides. It currently includes models from Garmin, FlightScope, Foresight/Bushnell, Rapsodo, Square and Uneekor EYE MINI. Treat each model individually; EYE MINI documentation does not establish support for every Uneekor device.

Prepare the connection

Install the Windows simulator through the vendor's current download flow. Follow the model guide for network/USB/Bluetooth, sign-in and simulator entitlement. Connect in Awesome Golf and verify an actual shot before configuring FluJado.

Direct versus assistant presets

The catalog contains both direct and assistant routes for some monitors, notably R10 and MLM2PRO. Select the route matching the vendor instructions and your working installation. Do not start an extra connector solely because another launch monitor needs one.

In the Hub

Select the matching Awesome Golf preset. Most assisted routes open Awesome Golf and wait for you to confirm the manual connection. The existing Square Omni route has model-specific automatic selection. A running Awesome Golf process is not proof of a live device connection.

Your acceptance check

Confirm the right monitor name in the simulator, hit one real shot, restart and repeat. If manual confirmation appears, confirm only after connection is ready. Report app startup, monitor connection and shot delivery separately.

# 7. Troubleshooting and handover

App opens, but no shots

Check the monitor connection first, then the simulator output and selected route. Ensure another connector is not already holding the device. For rela, confirm the Device and Simulator rows rather than repeatedly clicking Simulator Connect first. Source: rela connection troubleshooting.

Plugin not found or wrong monitor appears

Check the DLL is next to the correct rela.exe, matches the intended model and is the only competing Other plugin. Obtain the current release instructions from its author. Leave built-in dependencies alone.

Vendor update just installed

Finish activation/update prompts outside the Hub, then recheck the manual connection. Record old and new app, firmware and connector versions. Rela's red setup results may require rerunning its installer after vendor changes; see setup repair guidance.

What to send with feedback

Launch monitor model and firmware; simulator and connector versions; chosen Hub preset; connection type; exact order followed; expected result; actual result; whether a real shot arrived; a reviewed diagnostic report. Remove keys, passwords and private details. Send to info@flujado.com.

What remains to be verified

Current installer/plugin versions and binary contents; binary signatures/checksums; exact plugin/model version compatibility; fresh-PC and hardware tests for community routes. Documentation availability and physical compatibility are recorded separately.

Each row refers to an existing beta.18.3 preset. Required app names come from the shipped catalog, not a promise that no other setup is needed. Sources marked catalog reference were not individually re-read in this session. No preset in this index should be read as a blanket Verified badge.

# 8. Infinite Tees - beta.18.3 automatic and assisted routes

Install and prepare

Install and activate Infinite Tees and the correct connector first. FluJado does not ship vendor binaries, pair devices or provide simulator licenses. Select Infinite Tees in Guided setup, then choose the exact hardware preset and check program locations.

rela: correct connection order

Open Practice or a round in Infinite Tees and wait for the range/course to load. In rela select Simulator: Infinite Tees and the intended Device. Close other connector sessions. Use Device Search first; allow the device to connect and then the simulator. Simulator Connect is a recovery action after the device has connected. Confirm both show Connected and Ready, then check a real shot. The ProTee VX/plugin and Square Omni profiles now run Device Search and simulator recovery automatically, without Continue. For ProTee VX, rela starts Labs through its plugin; do not start Labs first.

ProTee VX through rela - practically tested

Use Other with the matching ProTeeVXPlugin.dll next to rela.exe. Use the configured Socket Relay and ProTee Labs. Keep only the intended Other plugin active. On 17 October 2026 the assisted beta.14 workflow, Connected/Ready status and a real shot in Infinite Tees Flat Range passed locally using an isolated connector copy.

Square Omni through rela Bluetooth - practically tested

Use the built-in Square Omni device and Bluetooth option. On 17 October 2026 the assisted beta.14 workflow, Connected/Ready status and a real shot in Infinite Tees Flat Range passed locally using an isolated connector copy.

Other presets and limits

The alternative ProTee VX Connector route and the other 10 Infinite Tees presets remain available but have not passed these hardware tests. A successful test for one connector does not transfer to another connector or monitor. Clean-install/reboot certification is still pending for the two tested routes.

Switching simulators and recovery

For these automatic profiles FluJado selects the expected Device and Simulator only while rela is closed, backing up its settings and retaining other values. Review the selection when using other assisted profiles. If no shots arrive, check Device first, then simulator output, plugin identity and other running connector sessions. Do not reset existing routes or license storage.

# 9. beta.18.3 - rela / ProTee startup order

Applies to both profiles

ShotForge / ProTee VX via rela and Infinite Tees / ProTee VX via rela now let the plugin own Labs startup. Install and configure ProTeeVXPlugin.dll and Socket Relay first. The Hub closes the conflicting sessions, starts the simulator and rela, searches for the device and lets the plugin start Labs. Do not add a preliminary Labs launch. The native GSPro and VX Connector routes retain their own order.

Automatic status checks

The Hub requires both device and simulator Connected and Ready, then checks Labs readiness and checks the connector again. Device Search precedes simulator Connect. Connection retries and timeouts are bounded; failure stops the route with diagnostics. Select a range or course yourself. First-use pairing, activation, plugin configuration and real-shot verification remain your responsibility.

Existing settings and practical evidence

Upgrades preserve saved user workflows and licenses. To use a newer preset in an existing setup, explicitly replace that route through Guided setup. Infinite Tees ProTee VX and Square Omni automatic startup/switching passed locally against the existing GSPro/ProTee VX tile and back. beta.14 real-shot evidence is historical; no new shot or GSPro/Square Omni hardware test is claimed. ShotForge startup order is covered by isolated tests in this release, not a new live hardware test.

# 10. VTrack Bridge and unresolved routes

Experimental VTrack route

For Infinite Tees, choose the exact LAON VTrack automatic-buttons preset only when you intend to test the reviewed VTrack Bridge v8 build. Configure the real IT_Golf_Launcher.exe. Windows English OCR and the recognised executable hash are required. Keep the launcher visible and still. Recognition is relative to the launcher window, so another screen/location is supported by design; moving/resizing during recognition rejects the click. Other builds or unavailable OCR require the assisted route.

What still needs testing

Automatic Connect and Start VTrack bridge control remains untested with VTrack hardware. Connected/Bridge running describes the interface, not proven device readiness. Confirm device discovery, Auto-send shots, Club/Hand and a real shot in Infinite Tees. Stop on errors. Uneekor additional information is pending; MuniGolfSim and Drills Golf Sim routes are still research items. # Drills - beta.18.3 connector routes

Drills setup and game choice

Install and sign in to Drills and configure your connector first. In FluJado open Settings > Overview > Open guided setup, enable Drills, and choose your exact launch monitor and route. Existing active flows stay unchanged unless you explicitly select replacement. To apply an updated preset to an existing route, back up first and explicitly replace that selected workflow.

Screens and startup

Keep your existing screen selection. New simulator profiles inherit the configured simulator screen, including older installations with one shared per-tile screen choice. The physical monitor identity is used, not its changing Windows display number. Drills opens on that screen and leaves game selection to you: Open Range is never chosen by FluJado.

ProTee VX and Square Omni

These two Drills routes connected and delivered real shots in local tests. ProTee VX switching with GSPro also passed. A GSPro/Omni shot was not verified in that switching session because the installed GSPro connector offered only ProTee. A controlled one-time ProTee startup recovery is available; its recovery branch was tested with isolated fixtures.

Other launch monitors

15 additional Drills profiles show Not tested (assisted). They require one manual connection confirmation and are not automatic proof of device readiness. Square HE, Garmin R10, SkyTrak OG/+/Max, Bushnell LPi and native VTrack have device-specific Discord guidance. The remaining rela combinations are candidates based on documented connector inputs and the Drills output. Check the compatibility table for each exact profile.

VTrack and LPi

The native VTrack route uses VTrack in the Drills launcher, not Other, with VTrack Toolkit and the Infinite Tees bridge closed. LPi uses the compatible OtherForesightPlugin.dll beside rela.exe; conflicting ProTee/Other plugins are rejected. Plugins are not bundled.

Off-center hitting mat

During a drill, press Esc and inspect its camera settings. Adjust the view for your own mat and verify the result visually. No universal numeric offset is documented here. FluJado updates preserve Drills settings and do not set the camera offset.

ShotForge and MSI update

ShotForge startup/readiness and supported connector checks have been improved. The MSI upgrade order now handles newly added application files before finishing the upgrade; rollback and cancellation were tested in an isolated product family. The update does not replace saved workflows automatically.
