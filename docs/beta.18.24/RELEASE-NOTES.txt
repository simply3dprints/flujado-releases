## Nederlands

18.24 herstelt de herkenning van de Windows Installer-registratie. De Hub kan daardoor zijn bestaande installatie en herstel-MSI vinden. Kom je van 18.22, werk dan bij via **Menu → Check for updates → Install update**. Als je al op 18.23 zit en bijwerken vanuit de Hub mislukt, sluit de Hub dan en open de 18.24-MSI. Gebruik je bestaande installatiemap.

## English

18.24 restores Windows Installer registration detection so the Hub can find its installed product and recovery MSI. From 18.22, use **Menu → Check for updates → Install update**. If updating from the Hub fails on 18.23, close the Hub and run the 18.24 MSI. Use your existing installation folder.

[Features introduced in beta.18.23](../beta.18.23/README.md). Remote Control follows separately.
