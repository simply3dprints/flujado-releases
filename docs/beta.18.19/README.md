## English

If FluJado is already installed via MSI, use **Install update** in the Hub. On a new PC, install and test the simulator and connector software first, then install FluJado. A pre-MSI installation can use the transition installer offered in the Hub.

For a PurePlay ProTee VX tile, update PurePlay in its own launcher if it shows **Update**. Test the switch to GSPro and back. Check that PurePlay and its launcher both close on the first switch and that GSPro opens before FluJado reports completion. No shot is needed for this check.

## Nederlands

Gebruik **Install update** in de Hub als FluJado al via MSI is geïnstalleerd. Installeer en test op een nieuwe pc eerst de simulatoren en connectors en daarna FluJado. Een oudere EXE-installatie kan via de Hub overstappen op MSI.

Toont de PurePlay-launcher **Update**, werk PurePlay dan eerst bij via die launcher. Test met de ProTee VX-tegel de wissel naar GSPro en terug. Controleer of de PurePlay-game en launcher sluiten en of het GSPro-spelvenster zichtbaar is voordat FluJado gereed meldt. Hiervoor zijn geen slagen nodig.
